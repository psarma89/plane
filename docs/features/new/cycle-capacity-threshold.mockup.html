Seven decisions that this drawing forces.

1. An empty capacity draws nothing in the panel. No meter, no alert, and no reserved space. Most cycles will never carry a capacity, so the panel must not grow for them.

2. The toggle renders on the form even with no capacity, and it is disabled. Hiding it hides the feature from the person most likely to want it.

3. The ok verdict shows the meter and no alert. An always-visible green banner trains the user to ignore the amber one.

4. The two alerts share one slot. The color changes and the second sentence changes. The title does not, because the fact is the same in both modes.

5. The bar caps at 100% and the label carries the real number. A warn-mode cycle can reach 43 of 40, and a bar that overflows its track reads as a rendering defect.

6. The refusal message names three numbers: the incoming points, the current points, and the capacity. A message that only says "over capacity" sends the user hunting for the arithmetic.

7. The block alert names the two ways out, because block mode is the only state where the user cannot simply continue.

Background levels, from the plane-backgrounds skill.

The modal sits on its own z-index plane, so it takes bg-surface-1. The cycle panel is a top-level container, so it also takes bg-surface-1. They are siblings, not a nest.

Each input and the toggle track are form controls, so they take bg-layer-1, one level above their surface. That is the one allowed exception. The selected half of the toggle returns to bg-surface-1 to read as raised.

The meter track takes bg-layer-1, because it is content inside a surface. The two alerts replace the layer with a semantic tint: bg-warning-subtle with border-warning-subtle and text-warning-primary, then bg-danger-subtle with border-danger-subtle and text-danger-primary. A tint is a color, not a fourth level.

Five decisions that this drawing forces.

1. An empty capacity draws nothing. No meter, no alert, no reserved space. Most cycles will never carry a capacity, so the panel must not grow for them.

2. The ok verdict shows the meter and no alert. An always-visible green banner trains the user to ignore the amber one.

3. The warn alert and the block alert sit in the same slot. Only one renders. The color and the verb change, and the layout does not move.

4. The block message names three numbers: the points that arrive, the points that are there, and the limit. A message that only says "over capacity" sends the user hunting for the arithmetic.

5. The 90% mark stays on the track in every state, so the user can see where the warn point sits before it fires.

Background levels, from the plane-backgrounds skill.

The modal sits on its own z-index plane, so it takes bg-surface-1. The cycle panel is a top-level container, so it also takes bg-surface-1. They are siblings, not a nest.

Each input is a form control, so it takes bg-layer-1, one level above its surface. That is the one allowed exception.

The meter track takes bg-layer-1, because it is content inside a surface. The two alerts replace the layer with a semantic tint: bg-warning-subtle with border-warning-subtle and text-warning-primary, then bg-danger-subtle with border-danger-subtle and text-danger-primary. A tint is a color, not a fourth level.

# Design system backgrounds

The Canvas, Surface, and Layer rules for this package live in the `plane-backgrounds` skill at `.claude/skills/plane-backgrounds/`.

- `.claude/skills/plane-backgrounds/SKILL.md` — the nine rules, the semantic text and border colors, and the decision order.
- `.claude/skills/plane-backgrounds/references/patterns.md` — six worked layouts: app root, card, modal, sidebar, list, form.
- `.claude/skills/plane-backgrounds/references/mistakes.md` — the five anti-patterns, each with a fix, plus a review checklist.

Claude Code does not load an `AGENTS.md` file on its own, so this file cannot reach a session by itself. The skill can, through its description. Edit the skill, not this file.
